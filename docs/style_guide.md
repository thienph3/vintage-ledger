# Vintage Ledger — Style Guide (R7)

## 1. Design Philosophy

**Core Idea**

> A soft, modern interface that feels like a shared daily journal — not a finance tool.

The UI should feel like:

* texting your partner about money
* casually sharing daily life
* lightweight and non-judgmental

NOT like:

* accounting software
* banking apps
* spreadsheets

---

## 2. Design Principles

### 2.1 Human over Financial

* Use natural language
* Avoid rigid financial terminology
* Prioritize readability over precision

### 2.2 Soft over Sharp

* No harsh contrasts
* No aggressive alerts
* Everything should feel calm and forgiving

### 2.3 Social over Personal

* Design for *shared visibility*
* Always show "who did what"
* Encourage interaction (reaction, awareness)

### 2.4 Fast over Detailed

* Optimize for 3-second scanning
* Reduce cognitive load
* Minimize input friction

---

## 3. Visual Direction

### 3.1 Overall Style

**Modern Structure + Soft Personality**

* Clean layout
* Generous spacing
* Minimal decoration
* Light emotional layer (emoji, tone, wording)

---

## 4. Typography

### 4.1 Font Strategy

* **Primary Font**: Clean sans-serif (e.g. Inter / SF Pro)
* **Accent Font**: Optional soft personality font (used sparingly)

### 4.2 Rules

* Do NOT use handwriting font as primary
* Avoid overly decorative fonts
* Maintain high readability

### 4.3 Usage

* Titles: slightly larger, soft weight (600)
* Body: regular (400)
* Numbers: clear, aligned, easy to scan

---

## 5. Color System

### 5.1 Base Colors

* Background: off-white (not pure white)
* Surface: very light neutral

### 5.2 Accent Colors

Use muted, warm tones:

* Soft blue
* Warm orange
* Light pink
* Gentle green

### 5.3 Rules

* Avoid high saturation
* Avoid strong red (feels like warning)
* Colors should feel “daily life”, not “finance”

---

## 6. Layout & Spacing

### 6.1 Structure

* Clear vertical hierarchy
* Large spacing between sections
* Avoid dense layouts

### 6.2 Spacing Scale

* 4 / 8 / 12 / 16 / 24 / 32

### 6.3 Corner Radius

* Use large radius: 16–20
* Avoid sharp corners

---

## 7. Components

### 7.1 Cards

* Clean background
* Subtle shadow
* No heavy borders

Content should feel:

* lightweight
* easy to scan

---

### 7.2 Transaction Item (Core Component)

Transform from data → story

**Avoid:**

* “Food - 80,000 VND”

**Use:**

* “Minh ăn trưa 80k 🍜”
* “Lan mua trà sữa 45k 🧋”

Rules:

* Always include actor (who)
* Use natural language
* Add emoji when appropriate

---

### 7.3 Quick Add

**Design Goal:** Chat-like, not form-like

* Input looks like message bar
* Suggestions as tappable chips

Examples:

* “Cafe 30k”
* “Ăn trưa 80k”

Rules:

* 1-tap actions
* Minimize typing
* Prioritize speed over accuracy

---

### 7.4 Reaction System

* Use emoji reactions
* Display who reacted
* Lightweight animation (pop/bounce)

Purpose:

* Add emotion
* Create interaction loop

---

## 8. Content & Tone

### 8.1 Writing Style

* Casual
* Conversational
* Friendly

### 8.2 Examples

Instead of:

* “Total spending today: 120,000 VND”

Use:

* “Hôm nay tụi mình tiêu 120k 😅”

---

### 8.3 Do

* Use “tụi mình”, “hôm nay”, “tuần này”
* Keep sentences short
* Add light emotion

### 8.4 Don’t

* Sound like report
* Use formal financial language
* Over-explain

---

## 9. Interaction Design

### 9.1 Feedback

* Immediate
* Subtle
* Non-blocking

### 9.2 Animations

* Fast (150–250ms)
* Smooth
* Purposeful

Avoid:

* heavy motion
* distracting transitions

---

## 10. Home Screen Structure (R7)

Keep minimal:

1. Today Total
2. Shared Feed
3. Quick Add

Remove:

* complex insights
* heavy dashboards
* unnecessary widgets

---

## 11. What to Avoid

### ❌ Too Vintage

* paper textures
* sepia overload
* handwriting everywhere

### ❌ Fintech Clone

* bank-style UI
* aggressive charts
* corporate feel

### ❌ Overly Cute

* childish visuals
* too many stickers
* loss of trust

---

## 12. Final Definition

> Vintage Ledger is not a tool to track money.
> It is a space where couples casually share and understand their daily spending.

---

## 13. Design Checklist

Before shipping any UI, ask:

* Is this easy to understand in 3 seconds?
* Does this feel like sharing, not tracking?
* Is this reducing friction or adding it?
* Would a couple feel comfortable using this together?

If any answer is “no” → redesign.
